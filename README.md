# BarLink

> Часть портфолио: [сайт-портфолио](https://auryxn.github.io/site-admin/) — репозиторий сайта [site-admin](https://github.com/auryxn/site-admin).

> Веб-MVP «знакомства в барах»: выберите заведение на карте, создайте встречу (BarLink) или присоединитесь к чужой.

## Что это

BarLink — приложение, которое помогает **познакомиться с людьми в барах и
клубах**. Вы открываете карту с реальными заведениями Вильнюса, выбираете место
и либо создаёте «BarLink» — открытую встречу с заданными параметрами, либо
присоединяетесь к уже созданной.

У каждой встречи сразу понятен её «вайб»: сколько человек хотят собрать, насколько
все настроены выпить, во сколько начинаем, на каком языке общаемся и по каким
интересам (хештеги вроде #настолки, #танцы, #пиво). У встречи есть список
участников и групповой чат.

Проект сделан как MVP для портфолио под грант. Демо полностью работает локально
(без ключей и внешних сервисов) и показывается внутри «рамки телефона», поэтому
всё кликается прямо из браузера на ноутбуке.

## Возможности

- **Интерактивная карта** баров и клубов Вильнюса (12 реальных заведений, пины,
  бейдж с числом активных встреч).
- **Карточка заведения** — фото, описание, рейтинг, адрес.
- **Создание BarLink** — число людей, уровень опьянения, время начала, язык,
  хештеги, заметка.
- **Присоединение / выход** из встречи; живой список участников.
- **Групповой чат** для каждой встречи (хост + участники).
- **Лента** всех активных встреч с поиском (по заведению / тегу / хосту).
- **Профиль** с «рейтингом выпитого» и мгновенным переключением демо-пользователя.
- **Демо-интерфейс в рамке телефона** — всё кликается в браузере на десктопе.

## Идея

Бары и клубы на карте. В каждом месте можно либо **создать BarLink**, либо
**к нему присоединиться**. Встреча задаёт настрой заранее:

- **число людей** — сколько человек хочет собрать компания;
- **уровень опьянения** — 😇 трезвый / 🙂 слегка / 😄 уже хорошо / 🤪 в говно;
- **время начала**, **язык**, **хештеги** (#настолки, #танцы, #пиво…).

## Стек

| Слой      | Технология |
|-----------|------------|
| Frontend  | React 18 + Vite + Tailwind + lucide-react |
| Карта     | Leaflet + react-leaflet (тёмные тайлы CARTO / OpenStreetMap, без ключей) |
| Backend   | Node + Express |
| БД        | SQLite (better-sqlite3) — без настройки |
| Авторизация | Демо-сессия по токену (заголовок `x-auth`) |

## Запуск

```bash
npm install
npm run db:seed     # создать data/barlink.sqlite + 12 заведений, 6 юзеров, 6 встреч
npm run server      # API  -> http://localhost:5181
npm run dev         # веб  -> http://localhost:5180
```

Откройте **http://localhost:5180** — приложение показывается внутри рамки телефона.

Дополнительно:

```bash
npm run build       # прод-сборка фронтенда
npm run preview     # предпросмотр сборки
npm start           # запуск API-сервера (то же, что `server`)
```

## API (кратко)

```
GET  /api/health
GET  /api/users
POST /api/login                 { userId | name }  -> { token, user }
GET  /api/me

GET  /api/venues                заведения + счётчик активных встреч
GET  /api/venues/:id            заведение + его активные BarLink

GET  /api/barlinks?venueId=     активные BarLink (с деталями)
POST /api/barlinks              создать (нужна авторизация)
GET  /api/barlinks/:id
POST /api/barlinks/:id/join     (авторизация)
POST /api/barlinks/:id/leave    (авторизация)
GET  /api/barlinks/:id/messages
POST /api/barlinks/:id/messages (авторизация)
GET  /api/my/barlinks           (авторизация)
```
